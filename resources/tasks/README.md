# Локальный задачник

Lapki загружает задачи один раз при запуске приложения. Чтобы добавить задачу,
положите файл с окончанием `.task.json` в эту папку или любую вложенную папку и
перезапустите приложение. Общий manifest не нужен.

Минимальная структура:

```json
{
  "schemaVersion": 1,
  "id": "unique-task-id",
  "version": 1,
  "title": "Название",
  "summary": "Краткое описание",
  "description": "# Полное описание в Markdown",
  "platformId": "junior-reader",
  "tests": [
    {
      "id": "first-test",
      "title": "Первый тест",
      "timeoutSeconds": 10,
      "input": { "message": "ABC" },
      "checks": [
        {
          "type": "reader.impulses.equals",
          "expected": ["impulseA", "impulseB", "impulseC"]
        }
      ]
    }
  ]
}
```

Все поля schema v1 строгие: опечатка или неизвестное поле делают файл
некорректным. `timeoutSeconds` — необязательное поле теста; по умолчанию
используется 10 секунд. Допустимый диапазон — 1–30 секунд. В задаче
может быть не более 32 тестов и не более 300 секунд суммарного timeout.

Поддерживаемые платформы и проверки:

- `junior-gardener`: `gardener.field.equals`, `gardener.position.equals`;
- `junior-reader`: `reader.impulses.equals`.

Для теста `junior-gardener` можно указать необязательную маску `hiddenCells`.
Это сетка логических значений того же размера, что и `input.field`: `true`
скрывает содержимое клетки знаком `?`, `false` показывает её. Стартовая клетка
должна быть открыта. Под маской может находиться стена, пустая клетка или
растение. Маска действует на входное поле, результат и историю шагов, но не
меняет поведение Садовника и проверку ответа. Например, для поля 3×2:

```json
"hiddenCells": [[false, true, true], [false, true, false]]
```

Скрытые клетки остаются закрытыми после решения. Маркер Садовника виден поверх
них. Маска создаёт учебный эффект; исходные данные остаются доступными в
локальном файле задачи.

Все проверки одного теста должны пройти. Ожидаемые значения хранятся в поле
`expected`. Они скрыты в интерфейсе, но не являются секретом от пользователя,
который читает локальные файлы приложения.

Изображение в Markdown подключается относительным путём:

```md
![Пример поля](images/example.png)
```

Файл изображения должен находиться внутри `resources/tasks`. Удобно хранить
задачу и изображения в отдельной вложенной папке. Абсолютные и сетевые ссылки
на изображения не принимаются.

Полный работающий пример находится в
[`gardener-letter-a.task.json`](gardener-letter-a.task.json).
